# Set up two-factor authentication (2FA)

## Why

2FA adds a second login step — a 6-digit code from your phone — so a stolen
password alone cannot access your account. Accounts with 2FA are much less
likely to be targeted by account-takeover attacks.

## Supported 2FA methods

- **Authenticator app (TOTP)** — recommended. Works with Google
  Authenticator, Authy, Microsoft Authenticator, 1Password, Bitwarden.
- **SMS OTP** — available as a fallback but less secure (SIM-swap risk).
- **Email OTP** — available but least secure; only suitable if you have no
  alternative.

## Enable TOTP

1. **Profile → Security → Two-factor authentication**
2. Click **Set up authenticator app**
3. Scan the QR code with your app
4. Enter the 6-digit code your app shows to confirm
5. **Save the recovery codes** shown on the screen — 10 single-use codes
   that let you log in if you lose your phone. Store them offline.

## Enable SMS 2FA

1. **Profile → Security → Two-factor authentication → SMS**
2. Enter your phone number (international format)
3. Enter the code we send to confirm

## Lost your authenticator

Use a **recovery code** at the login step. Each code works once.

If you've used all recovery codes and lost the authenticator, contact
support with:

- Your registered email
- A selfie with your ID (the same one used for KYC)

A human agent will reset 2FA within 48 hours. During this time the account
is locked for security.

## Rotating 2FA

You can remove and re-add the authenticator any time. When you remove 2FA,
the account briefly drops to single-factor — re-add immediately.

## 2FA for withdrawals only

Under Security you can require 2FA only on withdrawal, not on every login.
Good compromise between security and convenience.
