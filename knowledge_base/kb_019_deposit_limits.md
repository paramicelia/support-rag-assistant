# Personal limits: deposit, loss, session

You can set personal limits at any time. They override the platform-wide
defaults and apply only to your account. Lowering a limit is **instant**;
raising a limit takes 24h to take effect (cool-off by design).

## Available limits

### Deposit limit

Maximum you can deposit in a period.

- Daily, weekly, monthly options
- Any currency (matches your account currency)
- Once reached, the cashier blocks further deposits until the window rolls

### Loss limit

Maximum net losses (deposits minus withdrawals) in a period. Same daily,
weekly, monthly options. Once reached, wagering is blocked until the window
rolls. This is stricter than a deposit limit because winnings returned
don't "reset" the counter.

### Session limit

Maximum time per single session. When the limit is reached, an overlay asks
you to log out. A "reality check" pop-up also appears every 60 minutes by
default.

### Wager limit

Maximum you can stake in a period. Less common but available on request.

### Bet-size limit

Maximum per-bet stake. Useful for high-variance players.

## Where to configure

**Profile → Responsible Gambling → Limits.**

## How changes take effect

| Change         | Takes effect |
|----------------|--------------|
| Lowering any   | Immediately  |
| Raising any    | After 24h    |
| Removing any   | After 24h    |

The 24h cool-off is a regulatory requirement — it gives you time to
reconsider.

## Defaults

There are no mandatory defaults, but during registration we ask you to set
a deposit limit. You can skip this step; we recommend you don't.

## Reaching a limit

When you hit a limit, the cashier / game engine blocks the action and shows
a friendly message explaining which limit applies and when it rolls. You
are not penalised — the limit simply ticks down.
